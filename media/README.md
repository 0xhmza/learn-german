Place your own German video and SRT/WebVTT files here. Click **Refresh folder** in the app after adding files. No upload or duplicate browser copy is needed.

Examples:

```
simpsons.s06e01.mp4
simpsons.s06e01.de.srt
simpsons.s06e01.ar.srt
simpsons.s06e01.en.vtt
```

The catalog recognizes `simpsons.s06e01` through `simpsons.s06e25`, `simpsons.s07e01` through `simpsons.s07e25`, `spongebob.s03e01` through `spongebob.s03e20`, and `spongebob.s04e01` through `spongebob.s04e20`. Put a two-letter language code immediately before the subtitle extension. MP4/H.264/AAC and WebM are supported by modern browsers. Choose the German audio version. Files are scanned directly in this folder.

For UTF-16 or legacy subtitle files, use the app's import dialog and select an encoding if needed. Folder and browser files may be mixed; browser imports override folder files of the same type and language.
