# Grammatikinseln UX and learning audit

This audit describes the experience before the dashboard and study flow redesign. The [pilot protocol](learning-pilot.md) gives the tasks and measures for evaluating the updated experience with learners.

**The strongest reason to use Grammatikinseln is its Arabic explanation of German B1 grammar, with worked examples and linked practice. The weakest part is deciding what to do next.** The app has the parts of a good study session, but learners have to connect the lesson, practice, mistakes, flashcards and exam trainer themselves. The next release should make that sequence visible and use delayed practice to show what has stuck.

## Scope and method

I inspected the standalone app at desktop and phone widths, used fresh and returning learner states, and read the implementation plan and the code behind progress, review and exams. The walkthrough covers starting B1 grammar as an Arabic-speaking learner, coming back to work on a mistake, and preparing for telc B1 writing. At each step I looked at the goal the user would form, whether the action was visible, whether the label predicted what would happen, and whether the response confirmed progress. The friction points are expert predictions. Their frequency and impact still need observation with learners. The platform comparison uses official descriptions. [Wharton et al., *The Cognitive Walkthrough Method*](https://www.colorado.edu/ics/sites/default/files/attached-files/93-07.pdf)

## Cognitive walkthrough

| Learner goal and path | What the learner can see and infer | What happens and where the flow breaks |
| --- | --- | --- |
| **Start at the right level.** Home → Start the journey → Genitiv | The recommended card gives a concrete topic and level. A second start link leads to the same lesson. Rank, XP and the daily goal already take up prominent space when the learner has no history. | Genitiv opens directly. The default recommendation follows the curriculum order, so a learner who already knows it has to find the level filter or search. Offer one primary start action and visible choices for starting B1.1, continuing B1.2 or finding a rule. |
| **Understand and try a rule.** Lesson → worked example → practice | The colour-coded sentence roles, Arabic explanation and German word order make the rule inspectable. “Show all steps” helps someone who came for a quick reference. There are practice links in the banner and near completion. | The learner can open practice at once, or reveal all steps and mark the lesson complete with a star without answering. Give the learner a concrete objective and one short attempt after the example. Label the reading milestone “Explanation viewed” so its feedback reflects the action. |
| **Recover after a wrong answer.** Practice → check → explanation → next | Immediate feedback shows the correct answer and why. The link back to the lesson gives the learner somewhere to look. On an open-answer task, the learner sees a model and judges their own response. | The main action advances after feedback. There is no immediate second attempt on a comparable item. After a run, another full round is more prominent than repairing just the missed rules. Give a targeted cue, offer a fresh example, and explain when the skill will return for review. |
| **Pick up tomorrow.** Home → Today → overdue questions | The dashboard shows question reviews and mistakes. An unfinished practice run can be resumed from the practice launcher. Cards sit under a separate entry and have their own due queue. | A learner can return to a saved run and start due questions, but “no reviews due” on Home only describes the question queue. New flashcards also count alongside due flashcards inside the deck. Surface one recommended action for the current session and identify question reviews, card reviews and new cards by name. |
| **Practice one weak topic.** Sidebar search or map → island → lesson or island practice | The sidebar accepts Arabic and German search terms. The map and the list both support browsing. The island's practice button gives the whole group priority over any particular next lesson. | A whole-island round can contain dozens of questions. Some islands mix B1.1 and B1.2, and the island exam unlocks after all lessons across both sublevels have been marked complete. A learner whose dashboard is filtered to B1.1 may not know where the missing lessons are. Show the round length before starting, put “next lesson” first, and list the exact requirements alongside the lock. |
| **Prepare for telc.** Exams → choose a model → choose a section → submit or save | Reading and Sprachbausteine can be checked in place. The writing workspace keeps the message, task points and editor together, with a live word count and a saved draft. | All models are presented as peers. Listening displays statements without audio or automatic marking. The writing draft persists, but the next step after drafting is unclear because the workspace has no model response or scoring guidance. The menu has no speaking section. Label each skill's coverage in the catalogue and put the available next action on each result or draft screen. |

On a phone, the tall map and full topic listing make browsing a long scroll. Keep the map as an inviting way to explore, and give the searchable topic directory a shortcut above it. Make an Arabic keyboard and screen-reader pass part of acceptance for the complete journey, including focus after route changes, mixed-direction text, and quiz feedback. The [current implementation plan](grammar-platform-plan.md) already treats RTL and keyboard access as requirements.

The map in this update uses a static outline for the recommended island, and hovering changes the outline while the island and its label stay in place. The new illustration keeps available islands at full contrast. The phone layout gives island labels more room. This addresses the unstable target during browsing while keeping the map as a secondary route to the lessons.

## Where the product plan needs to change

- **Add what learners should be able to do.** The original grammar-only plan explicitly excluded learning goals and chapter themes. The product now includes contextual reading, application questions, flashcards and exam practice. Keep the ten-topic taxonomy and add concrete outcomes such as “I can report two past events in the right order using *nachdem*.” Link each outcome to its practice, related reading and exam-type task.
- **Make the signals honest.** One star can mean the learner finished viewing the explanation. Two or three stars reflect a lesson run at the 66% or 88% threshold, and self-marked writing can count. Stars can only increase. The island exam samples short items and excludes self-graded writing. These are useful milestones. Show reading, recent practice, and delayed success independently so learners can see what each milestone means. Keep XP and the boat as secondary signs of activity.
- **Define what “continue” means.** The dashboard chooses the first unfinished lesson and later the first lesson below three stars. The boat can represent the last visit or a change in progress, and the map's recommendation considers all levels. Make the main action account for unfinished sessions, overdue review and the selected level. Give the boat a consistent meaning and label the recommended island.
- **Connect review to a learning plan.** Questions and cards use separate records and fixed Leitner intervals of 1, 3, 7, 14 and 30 days. Due questions are offered in batches of up to 20. Present one short daily review session using both queues, with a clear count and a follow-up action. Cap new cards so a learner opening flashcards for the first time can start with the rules they've seen.
- **Keep offline use practical.** Browser-local storage and JSON backup make the app accessible without an account. Explain on the device what a saved draft or saved score means and make backup easier to find in Progress. Test reload, browser back, device change with a backup, and reset. Retain content IDs so changes to learning sequences preserve existing progress.

## What the research supports

A targeted search found no published evaluation of Grammatikinseln itself. The studies below inform specific design choices. Learning impact for Arabic-speaking B1 German learners still needs to be measured in this app.

- **Retrieval and spacing.** Roediger and Karpicke found that free recall of prose supported retention after a delay. Cepeda and colleagues found that the best interval for reviewing facts depended on how long learners needed to remember them. These findings support making learners retrieve a rule before revealing it and coming back to it later. Treat the app’s intervals as a starting point and test transfer by asking learners to complete a different sentence using the same rule a few days later. [Roediger & Karpicke, 2006](https://doi.org/10.1111/j.1467-9280.2006.01693.x) · [Cepeda et al., 2008](https://pubmed.ncbi.nlm.nih.gov/19076480/)
- **Mixing grammar structures.** Nakata and Suzuki found that 115 Japanese learners of English made more errors during interleaved practice but outperformed blocked practice on a grammaticality-judgment test one week later. This is closer to our use case than a memory experiment, though the language pair and outcome differ. Promote the existing cross-topic sets after the learner has seen the rules. A set contrasting *weil*, *deshalb* and *obwohl* can ask the learner to choose a connector for the meaning and then set the verb position. [Nakata & Suzuki, 2019](https://yuichisuzuki.net/wp-content/uploads/2023/04/Nakata-Suzuki-2019-MLJ.pdf)
- **Worked examples and pacing.** Mayer and Chandler found transfer benefits from learner-controlled segments in narrated animations about lightning. That is indirect evidence for our text-based examples. Keep the step-by-step view optional and make each step show a decision the learner can apply, such as identifying the clause boundary before placing the verb. Follow it with a new example and measure transfer. [Mayer & Chandler, 2001](https://tecfa.unige.ch/tecfa/teaching/methodo/Mayer_Chandler01.pdf)
- **Feedback and production.** Yang and Lyster compared different kinds of corrective feedback in English past-tense practice. The results depended on the verb type, and a later multisite study reported a more nuanced pattern. Our hints, worked corrections and open answers give a starting point. Try a rule-specific prompt and a second attempt before revealing the full answer, and give writing a checklist with examples of more than one acceptable response. These are product hypotheses drawn from classroom research. [Yang & Lyster, 2010](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/abs/effects-of-formfocused-practice-and-feedback-on-chinese-efl-learners-acquisition-of-regular-and-irregular-past-tense-forms/5B9530025AAD60E4B44699B79199365E) · [Multisite replication, 2023](https://doi.org/10.1111/lang.12623)
- **Arabic support.** Hall and Cook's international teacher survey documented use of learners' own languages in teaching. It provides context for Arabic explanations, with no direct estimate of their effect on German grammar outcomes. Keep Arabic available for instructions and difficult distinctions, and make the final task elicit German in a realistic context. Test Arabic explanations and mixed-direction examples with the intended learners. [Hall & Cook research summary, Northumbria University](https://www.northumbria.ac.uk/research/case-studies/re-assessing-own-language-use-in-english-language-teaching/)
- **Gamification.** In Sailer and colleagues' experiment, some combinations of game elements improved perceived competence. The experiment measured motivational outcomes. Keep the playful islands and use completion marks to explain what the learner actually accomplished. Track longer-term language performance separately from XP, clicks and streaks. [Sailer et al., 2017](https://opus.bibliothek.uni-augsburg.de/opus4/files/109059/109059.pdf)

## Recommended release order

| Priority | Change | How to evaluate it |
| --- | --- | --- |
| **1. Make starting and returning clear** | Put a single next action above rank and XP. Offer “Start B1.1,” “Start B1.2” and “Find a rule” as first-visit alternatives. Resolve unfinished sessions and review on return. Label how long a short practice will take. | Ask learners to start where they intend and resume after an interruption without help. Record time to first meaningful question, wrong turns and whether the learner can say what comes next. |
| **2. Pilot the full study sequence** | Start with temporal connectors and clause order. Give each lesson an outcome, an example, a short independent attempt and a retry on a new sentence. Schedule delayed practice with a different item and show that result separately from lesson viewing. | Compare a same-session score with performance on unseen items one week later. Include a constrained German production task. Track hinted, self-graded and automatically scored responses separately when interpreting results. |
| **3. Make exam coverage visible** | Add a per-model skill overview and direct resume for writing. Provide a writing checklist and worked reply for one model first. Add listening audio and validated keys and speaking scenarios in later increments. | Ask a telc candidate to pick one section, save a draft, recover it, and decide how to assess it. Compare section coverage against the official format. |
| **4. Consolidate practice and improve progress** | Route missed rules back into daily practice, expose due work across cards and questions, and make backup visible. Add a lightweight opportunity for German writing or speaking in each topic group. | Check whether learners can find a specific mistake, explain the difference between a star and current performance, return to a review after a break, and recover their progress from a backup. |

For the first usability round, recruit Arabic-speaking learners at both B1 sublevels, including phone users and telc candidates, and run these tasks without prompts. Use the observed problems to revise the next-action design before evaluating learning outcomes. For the first learning pilot, compare equally timed sessions on the same grammar points and score a delayed unseen exercise. That result will be more informative than changes in streaks or total rounds completed.
